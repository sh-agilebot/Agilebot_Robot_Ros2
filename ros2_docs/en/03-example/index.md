# Examples
This chapter provides some examples of Agilebot robot, including:
- [ROS2 Integration with AgileGaze](./01-AgileGazeDemo.md): Integrate the AgileGaze software with ROS2 to enable visual recognition features.
- [ROS2 Palletizing Demo](./02-PalletDemo.md): A complete workflow including visual recognition (optional simulation implementation), coordinate system setup, register writing, I/O triggering, script generation, and transmission.

> AgileGaze is a vision software developed by Shanghai Agilebott Robotics Co., Ltd. It allows implementation of commonly used vision algorithms in a flowchart format, including: color recognition, template matching, shape matching, QR code recognition, character recognition, and more.
