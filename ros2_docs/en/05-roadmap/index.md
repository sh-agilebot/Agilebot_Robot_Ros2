# Development Plan

This page outlines the main development roadmap for the Agilebot Robotics ROS2 project in Shanghai. It includes completed work and upcoming tasks to help community members and developers understand the project's progress. For specific product models of Shanghai Agilebot Robotics (Agilebot), please refer to the company website: [https://www.sh-agilebot.com/](https://www.sh-agilebot.com/)

## Completed Features

- **Added robot models and description files**
  - [x] GBT-C5A robot
  - [x] GBT-C7A robot
  - [x] GBT-C12A robot
  - [x] GBT-C16A robot

- **Added more simulation configurations**
  - [x] GBT-C5A robot
  - [x] GBT-C7A robot
  - [x] GBT-C12A robot
  - [x] GBT-C16A robot

- **MoveIt2 configuration**
  - [x] GBT-C5A robot
  - [x] GBT-C7A robot
  - [x] GBT-C12A robot
  - [x] GBT-C16A robot

## Planned Features

### Short-term Goals (Next few months)

- **Expand MoveIt2 Support**
  - [x] Complete MoveIt2 configuration for GBT-C7A, GBT-C12A, and GBT-C16A models
  - [x] Implement path planning through MoveIt2 and send commands to physical robots
  - [ ] Enable MoveIt2 control of real robots with path planning and obstacle avoidance capabilities

- **Expand Application Scenarios**
  - [ ] Extend to more industrial applications with demo implementations
  - [ ] Explore integration possibilities with other automation systems
