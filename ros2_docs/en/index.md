# Agilebot Robotics - ROS2 Software Package

## Project Overview

This project provides a ROS2 toolkit for Agilebot robots, designed to help users quickly integrate and develop robotic applications. The toolkit includes:

1. **Collaborative Robot URDF Model**  
   Provides standardized URDF description files for 3D modeling and simulation.

2. **ROS2 Driver Package**  
   Implements robot control and communication functions, supporting:  
   - Execution of control programs  
   - Sending program scripts to the robot  
   - Retrieving robot status information (joint/end-effector data, alarm information, etc.)  
   - Displaying the robot's current posture  

3. **Example Code and Tutorials**  
   Includes typical application cases to guide users in:  
   - Motion planning with MoveIt and execution on Agilebot robots  
   - Importing and executing offline trajectory files  
   - Integrating Agilebot's vision software AgileGaze  
   - Sending custom program scripts  
   - Vision-based palletizing demo  

This toolkit reduces integration complexity and improves development efficiency through comprehensive development resources.
