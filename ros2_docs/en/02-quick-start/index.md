# Quick Start

This guide will help you quickly set up and run the ROS2 project for Agilebot robots from Shanghai. We will cover how to launch RViz visualization, Gazebo simulation, and MoveIt2 configurations.

- [Visualize Agilebot Robot Model in RViz](./01-Visualize_URDF.md): Introduces how to visualize the Agilebot robot model using RViz.  
- [Simulate Robots in Gazebo](./02-Gazebo_Simulation.md): Explains how to simulate Agilebot robots using Gazebo.  
- [Robot Motion Planning with MoveIt2](./03-Moveit2_Simulation.md): Demonstrates robot motion planning using MoveIt2.  
- [MoveIt2 + Gazebo Co-simulation](./04-MoveIt2+Gazebo_simulation.md): Describes motion planning simulations combining MoveIt2 and Gazebo.  
- [Synchronize Robot Pose to RViz Display](./05-Synchronize_robot_pose.md): Shows how to synchronize the robot's real-time pose to RViz for visualization during programming or control.  
- [Publish Robot Status (Topic)](./06-publish_robot_status.md): Explains how to publish the robot's current status (Topic) for real-time updates in RViz.  
- [Robot Control Service Interfaces](./07-Service_interface.md): Lists commonly used service interfaces for robot control.  
- [MoveIt2 Control for Real Robots](./08-moveit_action_server.md): Demonstrates how to use MoveIt2 to control real robots. (*Under development, coming soon*)  
- [Send Scripts to the Robot for Execution](./09-send_script.md): Guides you through sending scripts to the robot for execution.
- [Control Robot Motion Using Offline Trajectory Files](./10-offline-trajectory.md): Explains how to control robot motion using offline trajectory files.
