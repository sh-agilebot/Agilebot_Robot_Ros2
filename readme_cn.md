# 上海捷勃特机器人 ROS2 项目

## 项目概述
该项目是上海捷勃特机器人产品对ROS2的支持（官网：http://www.sh-agilebot.com），包含URDF描述文件、Gazebo配置和MoveIt2配置，MoveIt2路径规划、离线轨迹等功能以及一些示例和演示。



```
├── assets                        # 资源文件
├── common                        # 通用文件
├── gbt_description               # URDF
├── gbt_driver                    # 软件包
├── gbt_gazebo                    # Gazebo配置
├── gbt_interface                 # 接口
├── gbt_moveit_config             # MoveIt2配置
├── gbt_stacking                  # 码放demo
├── gbt_stacking_interface        # 码放接口
└── gbt_vision                    # 视觉包，提供视觉相关demo
```

具体安装和使用方法请参考官方文档：[https://dev.sh-agilebot.com/docs/ros/zh/](https://dev.sh-agilebot.com/docs/ros/zh/)
